# Sweetty GL

A cross-platform, GPU-accelerated terminal emulator with shaders and effects. The goal is to provide a terminal experience with smooth text rendering, smooth cursor movement, and smooth scrolling.

## Target Platforms

*   Debian 13 on a Thinkpad T480 with an NVIDIA MX150 GPU
*   Asteroid OS on an Asus Zenwatch 3 (swift)
*   Asteroid OS on a Huawei Watch (sturgeon)
